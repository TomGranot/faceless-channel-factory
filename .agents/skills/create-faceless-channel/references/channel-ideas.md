# Channel ideas

Use these as starting points when the user wants adjacent concepts. Verify source access, rights, and platform terms before building.

## Evidence-ready pilots

| Idea | Official source | Why it fits |
| --- | --- | --- |
| Commons Picture Story | [MediaWiki APIs](https://www.mediawiki.org/wiki/API:Main_page) | Daily selection, durable file IDs, rich license metadata |
| Met Object Daily | [The Met Collection API](https://metmuseum.github.io/) | Public-domain flag, strong imagery, large evergreen inventory |
| Smithsonian Object Story | [Smithsonian Open Access](https://github.com/Smithsonian/smithsonian-openaccess) | Searchable CC0 media, object metadata, 2D and 3D assets |
| Library Time Machine | [Library of Congress API](https://www.loc.gov/apis/json-and-yaml/) | Free-to-use collections, canonical item pages, varied visual material |
| Quake Story | [USGS GeoJSON feeds](https://earthquake.usgs.gov/earthquakes/feed/) | Fresh event IDs, maps, impact data, public-domain source material |
| Filing Story | [SEC EDGAR APIs](https://www.sec.gov/search-filings/edgar-application-programming-interfaces) | Durable accession numbers, fresh filings, readable tables and text |

Read the repository's `docs/research/channel-source-feasibility.md` before selecting one of these pilots. It records the per-source rights gate and adapter evidence fields.

## High-potential formats to validate

These concepts survived the 2026-08-09 ADHD divergence run. They are promising formats, not source approvals. Read `docs/brainstorms/2026-08-09-adjacent-channel-ideas.md` for scoring, risks, and first experiments.

| Idea | Core loop | First validation |
| --- | --- | --- |
| Collection Detail Reveal | Crop, clues, full-object reveal | Render three public-domain Met objects and test whether the crop invites a guess |
| Package Signal | Adoption anomaly, package inspection, likely catalyst | Backfill 50 npm packages and manually verify the top five scores |
| Map Patch Notes | Before map, spot the change, after-map explanation | Score 100 non-bot Amsterdam changesets and verify the five clearest |
| Patent Puzzle | Figure clues, invention reveal, claimed mechanism | Render ten patents and check diagram legibility and claim accuracy |

Require ten publishable dry runs before creating a dedicated account. Track source-pass rate, capture-pass rate, human review time, and likely retention for each concept.

| Idea | What scrolls | Discovery source | Editorial angle |
| --- | --- | --- | --- |
| Product Hunt in 30 seconds | Product pages | Product Hunt API or approved feed | One launch worth trying today |
| New open-source AI tools | Repository READMEs and demos | GitHub search and releases | What the tool does before the hype |
| Papers with working demos | Paper page plus demo | arXiv categories and Papers with Code | The visible result, then the method |
| Design teardown daily | Public product flows | Curated submissions | One interface decision and its effect |
| Indie launch radar | Maker landing pages | RSS, launch feeds, newsletters | A small product with a sharp wedge |
| Data story of the day | Public chart or dashboard | Data portals and APIs | One surprising movement in the data |
| Security tool watch | Repository docs and safe demos | GitHub topics and vendor advisories | Defensive use, limits, and operator fit |
| Browser extension finds | Store listing and project page | Browser stores and public APIs | A task the extension removes |
| Automation recipe daily | Workflow canvas or docs | n8n, Zapier, Make galleries | Trigger, transformation, result |
| Useful government services | Public service pages | Government directories | A service people overlook |
| Accessibility fixes in the wild | Public UI examples | Curated submissions | One barrier and one concrete repair |
| Developer changelog radar | Release notes | RSS and GitHub releases | The update that changes daily work |
| New datasets | Dataset cards and samples | Hugging Face, Kaggle, data portals | What questions the dataset can answer |
| API of the day | Interactive documentation | Public API directories | One useful endpoint and a real output |
| Maps that explain a place | Public interactive maps | Data journalism and open GIS portals | One spatial pattern and why it matters |

Favor sources with stable IDs, structured discovery, mobile-readable pages, clear attribution, and enough visual material for a slow scroll. Avoid channels that depend on copied entertainment clips, personal data, medical claims, financial calls, or sources that block automated use.
