# Support

## Questions and setup help

Use GitHub Discussions for channel design, installation, source-policy questions, and help interpreting the documented contracts. Search existing discussions before opening a new one.

Include:

- the Agent Skills host and version;
- the command or workflow stage involved;
- the expected and observed behavior;
- a minimal sanitized configuration or fixture;
- validation output with secrets and account identifiers removed.

## Bugs

Use the bug-report issue form for deterministic repository defects. A provider incident or failed publication should include the error class and reconciliation state without authorization headers, cookies, raw responses, publication URLs, or account handles.

## Security and private data

Follow [SECURITY.md](SECURITY.md) for vulnerabilities. Do not place credentials, private account data, or identifying operating records in issues or discussions.

## Service expectations

This open-source repository does not include a hosted runtime or guaranteed response time. Provider billing, credentials, account recovery, platform appeals, and legal advice remain outside project support.
